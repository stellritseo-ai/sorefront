### Vercel Web Analytics Integration
Installed package: `@vercel/analytics`  
Configured in `src/routes/__root.tsx` via `@vercel/analytics/react` (the official React / Vite client implementation):
```tsx
import { Analytics } from "@vercel/analytics/react";

// Mounted within QueryClientProvider in RootComponent:
function RootComponent() {
  const { queryClient } = Route.useRouteContext();
  return (
    <QueryClientProvider client={queryClient}>
      <Outlet />
      <Toaster position="bottom-right" />
      <Analytics />
    </QueryClientProvider>
  );
}
```
> **Note on Framework Targeting:** The `@vercel/analytics/react` package is the native React runtime integration for Vite and TanStack Start. It provides real-time traffic insights, visitor attribution, and route change tracking directly in your Vercel Project Dashboard.
